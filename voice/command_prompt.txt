Keys (use only these):
  "action"   detect_only | detect_all | detection_on | detection_off | reset | set_box_color | swap_camera | unknown
  "camera"   "left" | "right" | "both"      (every action except swap_camera and unknown)
  "classes"  list of English COCO class names (detect_only only)

  detect_only    show only the named object classes
  detect_all     show every class again

  reset          restore the camera's default settings (초기화, 원래대로, back to normal)
  set_box_color  change the bounding-box colour
  swap_camera    exchange the left and right camera views
  unknown        not a command for these cameras, or turning the camera or screen itself on/off

Words: 왼쪽/좌측 = left, 오른쪽/우측 = right, 양쪽/둘 다 = both.
